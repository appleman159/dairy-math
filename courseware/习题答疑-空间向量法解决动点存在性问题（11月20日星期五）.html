空间向量法解决动点存在性问题 · 核心通法与防坑锦囊

第二步：向量三角形直接拆解目标向量（首选）

设动点比例 [[vec:A[[sub:1]]Q]] = λ[[vec:A[[sub:1]]N]]（λ ∈ [0, 1]）。若只求方向向量 [[vec:PQ]]，无需先求动点 Q 的坐标，直接用三角形法则拆解：[[vec:PQ]] = [[vec:PA[[sub:1]]]] + λ[[vec:A[[sub:1]]N]]，一步到位且减少符号错误！

第二步（备选）：原点位置向量法（求坐标专用）

只有当题目明确要求“写出动点 Q 的坐标”时，才需通过原点位置向量计算：[[vec:AQ]] = [[vec:AA[[sub:1]]]] + λ[[vec:A[[sub:1]]N]]。严禁出现“Q = A[[sub:1]] + λ[[vec:A[[sub:1]]N]]”或“[[vec:PQ]] = Q - P”等扣分写法！

第三步：交叉赋整式，消灭分母

求含参法向量遇到 2λy + (1 - λ)z = 0 时，切忌令 y = 1 产生分母！直接交叉令 y = λ - 1，则 z = 2λ，零分母零讨论。

第四步：解方程验范围，核对所求比值

解出 λ 后先核对是否在定义域内（不合题意立即舍去）；最后务必看清题目求的是 [[frac:SE|SC]] = λ 还是 [[frac:SE|EC]] = [[frac:λ|1-λ]]！
