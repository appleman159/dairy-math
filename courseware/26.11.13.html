01 · 典例分析与条件翻译

抓准三个几何条件，逐一翻译为代数方程

【典例】已知圆 $C$ 和 $y$ 轴相切，圆心在直线 $x - 3y = 0$ 上，且被直线 $y = x$ 截得的弦长为 $2\sqrt{7}$，求圆 $C$ 的方程。

思路引导：由于条件直接给出了圆心所在直线、与坐标轴相切及弦长，优先设圆的标准方程，共有 $a, b, r$ 三个待定参数：

$$(x - a)^2 + (y - b)^2 = r^2 \quad (r > 0)$$
1 圆与 $y$ 轴相切
圆心 $(a,b)$ 到 $y$ 轴距离等于半径 $\Longrightarrow$ $|a| = r$ （即 $a^2 = r^2$）
2 圆心在 $x - 3y = 0$ 上
将圆心坐标 $(a,b)$ 代入直线方程 $\Longrightarrow$ $a - 3b = 0$ （即 $a = 3b$）
3 被 $y = x$ 截得弦长 $2\sqrt{7}$
弦心距 $d = \dfrac{|a - b|}{\sqrt{2}}$，半弦长 $m = \sqrt{7}$ $\Longrightarrow$ $\dfrac{(a - b)^2}{2} + 7 = r^2$
02 · 必备核心知识点

解决本类题型的四个基本工具

① 圆的标准方程
$$(x - a)^2 + (y - b)^2 = r^2$$
圆心为 $C(a, b)$，半径为 $r > 0$。几何特征直观，凡涉及圆心与直线距离的问题均优先选用。
② 直线与圆相切
$$d = r$$
圆心到切线的距离等于半径。特别地：与 $x$ 轴相切 $\Rightarrow r = |b|$；与 $y$ 轴相切 $\Rightarrow r = |a|$。
③ 点到直线的距离
$$d = \frac{|Ax_0 + By_0 + C|}{\sqrt{A^2 + B^2}}$$
计算圆心 $(a,b)$ 到直线的弦心距或切线距离前，务必先将直线化为一般式 $Ax + By + C = 0$。
④ 垂径定理（勾股关系）
$$d^2 + m^2 = r^2 \quad \left(m = \frac{L}{2}\right)$$
弦心距 $d$、半弦长 $m$ 与半径 $r$ 构成 $\text{Rt}\triangle AHC$。本题弦长 $L = 2\sqrt{7}$，故半弦长 $m = \sqrt{7}$。

04 · 两种方法规范解答

方法一（标准方程法主讲）与方法二（一般方程法对照）

1

设圆的标准方程并列出方程组

设圆 $C$ 的标准方程为 $(x - a)^2 + (y - b)^2 = r^2 \ (r > 0)$。圆心 $C(a, b)$ 到直线 $x - y = 0$ 的弦心距为 $d = \dfrac{|a - b|}{\sqrt{2}}$，半弦长 $m = \sqrt{7}$，由题意得：

$$\begin{cases} |a| = r & \text{①（与 } y \text{ 轴相切）} \\[6pt] a - 3b = 0 & \text{②（圆心在直线 } x - 3y = 0 \text{ 上）} \\[6pt] \dfrac{(a - b)^2}{2} + 7 = r^2 & \text{③（垂径定理 } d^2 + m^2 = r^2\text{）} \end{cases}$$
💡 基础薄弱同学点此查看：详细联立消元步骤（如何解出 $a, b, r$） 查看消元演算
Step 1：用参数 $b$ 统一表示 $a$ 和 $r^2$
由方程 ② 得 $a = 3b$；代入方程 ① 并两边平方，得 $r^2 = a^2 = (3b)^2 = 9b^2$。
Step 2：代入方程 ③ 化为一元二次方程
将 $a = 3b$ 与 $r^2 = 9b^2$ 代入方程 ③ 中消去 $a$ 和 $r$： $$\frac{(3b - b)^2}{2} + 7 = 9b^2 \implies \frac{4b^2}{2} + 7 = 9b^2 \implies 2b^2 + 7 = 9b^2 \implies 7b^2 = 7 \implies b = \pm 1$$
Step 3：分类回代求得两组解
• 当 $b = 1$ 时，$a = 3b = 3$，半径 $r = |a| = 3$；
• 当 $b = -1$ 时，$a = 3b = -3$，半径 $r = |a| = 3$。
2

解得参数并写出圆的方程

联立 ①②③ 解得：

$$\begin{cases} a = 3 \\ b = 1 \\ r = 3 \end{cases} \quad \text{或} \quad \begin{cases} a = -3 \\ b = -1 \\ r = 3 \end{cases}$$
✅ 最终答案
故圆 $C$ 的方程为 $(x - 3)^2 + (y - 1)^2 = 9$ 或 $(x + 3)^2 + (y + 1)^2 = 9$。
1

设圆的一般方程并列出方程组

设圆的一般方程为 $x^2 + y^2 + Dx + Ey + F = 0 \ (D^2 + E^2 - 4F > 0)$，其圆心为 $\left(-\dfrac{D}{2}, -\dfrac{E}{2}\right)$，半径 $r = \dfrac{1}{2}\sqrt{D^2 + E^2 - 4F}$。由三个条件列方程组：

$$\begin{cases} E^2 - 4F = 0 & \text{①（与 } y \text{ 轴相切，令 } x=0 \text{ 得 } \Delta=0\text{）} \\[6pt] D - 3E = 0 & \text{②（圆心在直线 } x - 3y = 0 \text{ 上）} \\[6pt] \dfrac{(D - E)^2}{8} + 7 = \dfrac{D^2 + E^2 - 4F}{4} & \text{③（由 } d^2 + 7 = r^2 \text{ 化简所得）} \end{cases}$$
💡 基础薄弱同学点此查看：一般方程法的联立消元步骤 查看消元演算
Step 1：利用 ①② 将 $D$ 和 $4F$ 用 $E$ 表示
由 ① 得 $E^2 - 4F = 0$（即 $4F = E^2$）；由 ② 得 $D = 3E$。
Step 2：代入方程 ③ 解出 $E$
将 $D = 3E$ 和 $E^2 - 4F = 0$ 代入方程 ③： $$\frac{(3E - E)^2}{8} + 7 = \frac{(3E)^2 + 0}{4} \implies \frac{4E^2}{8} + 7 = \frac{9E^2}{4} \implies \frac{7E^2}{4} = 7 \implies E^2 = 4 \implies E = \pm 2$$
Step 3：回代求得 $D, F$
• 当 $E = -2$ 时，$D = 3E = -6$，$F = \dfrac{E^2}{4} = 1$；
• 当 $E = 2$ 时，$D = 3E = 6$，$F = \dfrac{E^2}{4} = 1$。
2

解得系数并写出圆的一般方程

联立 ①②③ 解得：

$$\begin{cases} D = -6 \\ E = -2 \\ F = 1 \end{cases} \quad \text{或} \quad \begin{cases} D = 6 \\ E = 2 \\ F = 1 \end{cases}$$
✅ 一般式答案
故圆 $C$ 的一般方程为 $x^2 + y^2 - 6x - 2y + 1 = 0$ 或 $x^2 + y^2 + 6x + 2y + 1 = 0$。
05 · 阶梯变式训练

独立思考作图与列式，再展开辅助图与解析核对

变式训练 1 基础巩固 · 割线过圆心特例
已知圆 $C$ 与 $x$ 轴相切，圆心在直线 $x + y - 4 = 0$ 上，且被直线 $x = 2$ 截得的弦长为 $4$，求圆 $C$ 的方程。
📐 思考后点此展开：几何辅助图 查看配图
圆心 $C(2,2)$ 恰在直线 $x=2$ 上（$d=0$），截得弦长 $4$ 即为直径，且与 $x$ 轴相切于 $(2,0)$
📝 点此查看：完整解析过程与答案 展开解析

解：设圆的标准方程为 $(x - a)^2 + (y - b)^2 = r^2 \ (r > 0)$。

圆心 $C(a,b)$ 到直线 $x = 2$ 的弦心距为 $d = |a - 2|$，半弦长 $m = 2$，由题意列方程组：

$$\begin{cases} |b| = r & \text{①} \\ a + b - 4 = 0 & \text{②} \\ (a - 2)^2 + 2^2 = r^2 & \text{③} \end{cases}$$

由 ①② 得 $r^2 = b^2 = (4 - a)^2$，代入 ③ 得：

$$(a - 2)^2 + 4 = (4 - a)^2 \implies a^2 - 4a + 8 = 16 - 8a + a^2 \implies 4a = 8 \implies a = 2$$

回代得 $b = 2, \ r = 2$。故所求圆的方程为 $(x - 2)^2 + (y - 2)^2 = 4$。

变式训练 2 对称双解 · 斜线截弦
已知圆 $C$ 与 $x$ 轴相切，圆心在直线 $x - 2y = 0$ 上，且被直线 $y = x$ 截得的弦长为 $2\sqrt{2}$，求圆 $C$ 的方程。
📐 思考后点此展开：几何辅助图 查看配图
第一、三象限各有一个满足条件的圆，圆心分别为 $(4,2)$ 和 $(-4,-2)$，半径均为 $2$
📝 点此查看：完整解析过程与答案 展开解析

解：设圆的标准方程为 $(x - a)^2 + (y - b)^2 = r^2 \ (r > 0)$。

圆心 $C(a,b)$ 到直线 $x - y = 0$ 的距离 $d = \dfrac{|a - b|}{\sqrt{2}}$，半弦长 $m = \sqrt{2}$，列方程组：

$$\begin{cases} |b| = r & \text{①} \\ a - 2b = 0 & \text{②} \\ \dfrac{(a - b)^2}{2} + 2 = r^2 & \text{③} \end{cases}$$

将 $a = 2b$ 与 $r^2 = b^2$ 代入 ③ 得：

$$\frac{(2b - b)^2}{2} + 2 = b^2 \implies \frac{b^2}{2} = 2 \implies b^2 = 4 \implies b = \pm 2$$

从而 $a = \pm 4$（与 $b$ 同号），$r = 2$。故圆 $C$ 的方程为 $(x - 4)^2 + (y - 2)^2 = 4$ 或 $(x + 4)^2 + (y + 2)^2 = 4$。

变式训练 3（本题为作业本题目） 📘 综合拔高 · 与一般直线相切及斜线截弦
已知圆 $C$ 的圆心在直线 $x + y - 2 = 0$ 上，圆 $C$ 与直线 $3x + 4y + 5 = 0$ 相切，且被直线 $4x + 3y - 14 = 0$ 截得的弦长为 $2\sqrt{3}$，求圆 $C$ 的标准方程。
📐 思考后点此展开：变式 3 几何辅助图 查看配图
圆心 $C(3,-1)$ 到切线 $3x+4y+5=0$ 的距离 $r=2$，到割线 $4x+3y-14=0$ 的距离 $d=1$，半弦长 $m=\sqrt{3}$
📝 点此查看：作业本题目完整解析过程 展开解析

解：设圆 $C$ 的标准方程为 $(x - a)^2 + (y - b)^2 = r^2 \ (r > 0)$。

① 因圆心在直线 $x + y - 2 = 0$ 上，故 $a + b - 2 = 0 \implies b = 2 - a$；

② 因圆与直线 $3x + 4y + 5 = 0$ 相切，圆心到切线的距离等于半径 $r$：

$$r = \frac{|3a + 4b + 5|}{\sqrt{3^2 + 4^2}} = \frac{|3a + 4(2 - a) + 5|}{5} = \frac{|13 - a|}{5}$$

③ 圆心到割线 $4x + 3y - 14 = 0$ 的弦心距 $d$ 为：

$$d = \frac{|4a + 3b - 14|}{\sqrt{4^2 + 3^2}} = \frac{|4a + 3(2 - a) - 14|}{5} = \frac{|a - 8|}{5}$$

已知弦长为 $2\sqrt{3}$，故半弦长 $m = \sqrt{3}$。由垂径定理 $d^2 + m^2 = r^2$ 得：

$$\frac{(a - 8)^2}{25} + 3 = \frac{(13 - a)^2}{25}$$

两边同乘 $25$ 并展开消去 $a^2$：

$$(a^2 - 16a + 64) + 75 = a^2 - 26a + 169 \implies 10a = 30 \implies a = 3$$

回代得 $b = 2 - 3 = -1$，半径 $r = \dfrac{|13 - 3|}{5} = 2$。故圆 $C$ 的标准方程为 $(x - 3)^2 + (y + 1)^2 = 4$。

06 · 通法归纳

待定系数法求圆方程的四步标准流程

STEP 01
设标准方程
凡涉及圆心位置、相切或弦长条件，优先设 $(x-a)^2+(y-b)^2=r^2$。
STEP 02
译几何条件
相切译为 $d=r$；圆心在直线上直接代入 $(a,b)$；弦长必用 $d^2+m^2=r^2$。
STEP 03
单参数消元
先利用一次方程将 $a,b$ 用同一个字母表示，再代入勾股关系式求解。
STEP 04
验根写方程
注意平方开方可能产生双解，逐一回代求得 $(a,b,r)$ 并写出标准式。
