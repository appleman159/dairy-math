01 · 核心例题与条件拆解

读题抓三条件，逐句翻译为代数方程

【典例】已知圆 C 与 y 轴相切，圆心在直线 x − 3y = 0 上，且被直线 y = x 截得的弦长为 2√7，求圆 C 的方程。

解题切入点：求圆的方程需要确定三个独立参数。由于条件直接涉及圆心位置、与坐标轴相切及弦长，优先设圆的标准方程：

(x − 𝑎)2 + (y − b)2 = r2   (r > 0)
1 圆与 y 轴相切
圆心 (𝑎, b) 到 y 轴距离等于半径 ⇒ |𝑎| = r （平方得 𝑎2 = r2）
2 圆心在 x − 3y = 0 上
将圆心坐标 (𝑎, b) 代入直线方程 ⇒ 𝑎 − 3b = 0 （即 𝑎 = 3b）
3 被 y = x 截得弦长 2√7
弦心距 d = |𝑎 − b|√2，半弦长 m = √7，由 d2 + m2 = r2 ⇒ (𝑎 − b)22 + 7 = r2
02 · 必备核心公式

解决圆的方程与弦长问题的四大工具

① 圆的标准方程
(x − 𝑎)2 + (y − b)2 = r2
圆心坐标为 C(𝑎, b)，半径为 r > 0。突出几何特征，适合已知圆心位置关系或相切条件的题目。
② 直线与圆相切
d = r
圆心到切线的距离等于半径。特别地：与 x 轴相切 ⇒ r = |b|；与 y 轴相切 ⇒ r = |𝑎|。
③ 点到直线的距离公式
d = |Ax0 + By0 + C|√A2 + B2
求圆心 (𝑎, b) 到截弦直线 Ax + By + C = 0 的弦心距时，必须先将直线方程化为一般式。
④ 垂径定理（弦长勾股关系）
d2 + m2 = r2   (m = L2)
弦心距 d、半弦长 m = L2 与半径 r 构成直角三角形 Rt▵AHC，切忌把整条弦长 L 直接当成 m！

04 · 两种方法规范解答

方法一（标准方程法主讲）与方法二（一般方程法对照）

1

设圆的标准方程并列出方程组

设圆 C 的标准方程为 (x − 𝑎)2 + (y − b)2 = r2  (r > 0)。圆心 C(𝑎, b) 到直线 x − y = 0 的弦心距 d = |𝑎 − b|√2，半弦长 m = √7，由题意列方程组：

{
|𝑎| = r ① 圆与 y 轴相切
𝑎 − 3b = 0 ② 圆心在直线 x − 3y = 0 上
(𝑎 − b)22 + 7 = r2 ③ 垂径定理 d2 + m2 = r2
💡 基础薄弱同学点此查看：详细联立消元步骤（手把手教你解方程组）
第 ① 步（用 b 表示 𝑎 和 r2）：
由方程 ② 得 𝑎 = 3b；将其代入方程 ① 并两边平方，得 r2 = 𝑎2 = (3b)2 = 9b2。
第 ② 步（代入方程 ③ 化为一元二次方程）：
把 𝑎 = 3b 和 r2 = 9b2 代入方程 ③ 中，消去 𝑎 和 r：
(3b − b)22 + 7 = 9b2 ⇒ 4b22 + 7 = 9b2 ⇒ 2b2 + 7 = 9b2 ⇒ 7b2 = 7 ⇒ b = ±1
第 ③ 步（分类回代求 𝑎, r）：
• 当 b = 1 时，𝑎 = 3b = 3，半径 r = |𝑎| = 3；
• 当 b = −1 时，𝑎 = 3b = −3，半径 r = |𝑎| = 3。
2

求解方程组并写出圆的方程

联立 ①②③ 解得：

𝑎 = 3,  b = 1,  r = 3 或 𝑎 = −3,  b = −1,  r = 3
最终结论（共两解）
故圆 C 的方程为 (x − 3)2 + (y − 1)2 = 9  或  (x + 3)2 + (y + 1)2 = 9。
1

设一般方程并列出关于 D, E, F 的方程组

设圆的一般方程为 x2 + y2 + Dx + Ey + F = 0  (D2 + E2 − 4F > 0)，圆心为 (−D2, −E2)，半径 r = 12√D2 + E2 − 4F。由题意列方程组：

{
E2 − 4F = 0 ① 与 y 轴相切 (令 x=0 得 y2+Ey+F=0, Δ=0)
D − 3E = 0 ② 圆心在 x − 3y = 0 上
(D − E)28 + 7 = D2 + E2 − 4F4 ③ 垂径定理 d2 + 7 = r2
💡 基础薄弱同学点此查看：一般方程法的联立消元步骤
第 ① 步（用 E 表示 D 与 4F）：
由 ① 得 E2 − 4F = 0（即 4F = E2）；由 ② 得 D = 3E。
第 ② 步（代入方程 ③ 求解 E）：
将 D = 3E 和 E2 − 4F = 0 代入 ③ 中：
(3E − E)28 + 7 = (3E)2 + 04 ⇒ 4E28 + 7 = 9E24 ⇒ 7E24 = 7 ⇒ E = ±2
第 ③ 步（回代求 D, F）：
当 E = −2 时，D = −6, F = 1；当 E = 2 时，D = 6, F = 1。
2

求解方程组并写出圆的一般方程

联立 ①②③ 解得：

D = −6,  E = −2,  F = 1 或 D = 6,  E = 2,  F = 1
一般式最终结论
故圆 C 的一般方程为 x2 + y2 − 6x − 2y + 1 = 0  或  x2 + y2 + 6x + 2y + 1 = 0。

📝 查看变式 1 完整解析与答案
第一步：设标准方程并列方程组
设圆的标准方程为 (x − 𝑎)2 + (y − b)2 = r2  (r > 0)。圆心 C(𝑎, b) 到直线 x = 2 的距离为 d = |𝑎 − 2|，半弦长 m = 2，列方程组：
{
|b| = r ① 与 x 轴相切
𝑎 + b − 4 = 0 ② 圆心在直线上
(𝑎 − 2)2 + 22 = r2 ③ 垂径定理 d2 + m2 = r2
第二步：联立消元求解
由 ①② 得 r2 = b2 = (4 − 𝑎)2，代入 ③ 得：
(𝑎 − 2)2 + 4 = (4 − 𝑎)2  ⇒  𝑎2 − 4𝑎 + 8 = 16 − 8𝑎 + 𝑎2  ⇒  4𝑎 = 8  ⇒  𝑎 = 2。
回代得 b = 2,  r = 2。
第三步：写出圆的方程
故圆 C 的方程为 (x − 2)2 + (y − 2)2 = 4。

设圆的标准方程为 (x − 𝑎)2 + (y − b)2 = r2  (r > 0)。圆心 C(𝑎, b) 到直线 x − y = 0 的弦心距 d = |𝑎 − b|√2，半弦长 m = √2，列方程组：
{

变式 3（本题为作业本题目） 综合拔高：与一般直线相切 + 被一般直线截弦

已知圆 C 的圆心在直线 x + y − 2 = 0 上，圆 C 与直线 3x + 4y + 5 = 0 相切，且被直线 4x + 3y − 14 = 0 截得的弦长为 2√3，求圆 C 的方程。

图 3：圆心 C(3, −1) 到切线 3x+4y+5=0 的距离 r = 2，到截线 4x+3y−14=0 的弦心距 d = 1，半弦长 m = √3
📝 查看变式 3（作业本题目）完整解析与答案
第一步：设标准方程并用点到直线距离公式列方程组
设圆 C 的标准方程为 (x − 𝑎)2 + (y − b)2 = r2  (r > 0)。
• 圆与直线 3x + 4y + 5 = 0 相切，圆心到切线距离等于半径：r = |3𝑎 + 4b + 5|√32 + 42 = |3𝑎 + 4b + 5|5；
• 圆心到截弦直线 4x + 3y − 14 = 0 的弦心距：d = |4𝑎 + 3b − 14|√42 + 32 = |4𝑎 + 3b − 14|5，半弦长 m = √3。
由此列出三元方程组：
{
𝑎 + b − 2 = 0  ⇒  b = 2 − 𝑎 ① 圆心在直线上
r = |3𝑎 + 4b + 5|5 ② 与 3x + 4y + 5 = 0 相切
(4𝑎 + 3b − 14)225 + 3 = r2 ③ 垂径定理 d2 + m2 = r2
第二步：消去 b，化为关于 𝑎 的方程
将 ① b = 2 − 𝑎 分别代入 r 和 d 的表达式中化简：
• 3𝑎 + 4(2 − 𝑎) + 5 = 13 − 𝑎  ⇒  r2 = (13 − 𝑎)225
• 4𝑎 + 3(2 − 𝑎) − 14 = 𝑎 − 8  ⇒  d2 = (𝑎 − 8)225
代入方程 ③ 得：
(𝑎 − 8)225 + 3 = (13 − 𝑎)225 ⇒ (𝑎2 − 16𝑎 + 64) + 75 = 𝑎2 − 26𝑎 + 169 ⇒ 10𝑎 = 30 ⇒ 𝑎 = 3
第三步：回代求 b, r 并写出圆的方程
将 𝑎 = 3 代入得 b = 2 − 3 = −1，半径 r = |13 − 3|5 = 2。
故所求圆 C 的标准方程为 (x − 3)2 + (y + 1)2 = 4。
06 · 通法归纳

待定系数法求圆方程的四步标准流程

STEP 01
设标准方程
凡涉及圆心在直线上、与直线相切、弦长条件，优先设 (x−𝑎)2+(y−b)2=r2。
STEP 02
译几何条件
相切译为 d = r；圆心在直线上直接代入 (𝑎, b)；弦长必用勾股 d2+m2=r2。
STEP 03
单参数消元
先用一次直线方程将 𝑎, b 统一为一个参数，再代入 d2+m2=r2 求解。
STEP 04
验根写方程
注意平方开方可能产生双解，逐一回代求得 (𝑎, b, r) 并规范写出标准式。
