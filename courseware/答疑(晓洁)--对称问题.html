01 · 核心例题与本质转化

圆关于直线对称，到底在求什么？

【例 15】 求与圆 $C: (x+2)^2 + (y-6)^2 = 1$ 关于直线 $l: 3x - 4y + 5 = 0$ 对称的圆 $C'$ 的方程。
🎯 核心降维本质：
圆在轴对称变换下形状、大小完全不变！因此：
① 半径相等： 对称圆半径 $r' = r = 1$；
② 圆心对称： 只需作出原圆心 $C(-2, 6)$ 关于直线 $l$ 的对称点 $C'(a, b)$，即可直接写出对称圆方程 $(x-a)^2 + (y-b)^2 = 1$。
02 · 求对称点 $C'(a,b)$ 的四大武器

常规通法 + 特殊斜率秒杀 + 一般对称公式

方法一 · 常规通法（一平二垂）
设点 $C(x_0, y_0)$ 关于直线 $Ax+By+C=0$ 的对称点为 $C'(a, b)$，利用对称轴是线段 $CC'$ 的垂直平分线列出两个一次方程：
$$\begin{cases} A\cdot\dfrac{x_0+a}{2} + B\cdot\dfrac{y_0+b}{2} + C = 0 & \text{(中点在轴上)} \\[8pt] \dfrac{b - y_0}{a - x_0} \cdot \left(-\dfrac{A}{B}\right) = -1 & \text{(连线垂直轴)} \end{cases}$$
💡 技巧： 垂直条件也可直接写为方向向量平行：$B(a - x_0) - A(b - y_0) = 0$，避免分母与斜率不存在的讨论。
补充视角 · 距离相等能列方程吗？
除了“中点 + 垂直”，也可以用点到直线的距离相等（$d_{C\to l} = d_{C'\to l}$）或 $|MC| = |MC'|$ 作为其中一个方程：
$$\frac{|Aa + Bb + C|}{\sqrt{A^2+B^2}} = \frac{|Ax_0 + By_0 + C|}{\sqrt{A^2+B^2}}$$
⚠️ 注意： 去绝对值会产生“$=$ 原值”（重合或平行移动，舍去）和“$= -$原值”（异侧对称）两解，结合“垂直”方程组解一次方程即可；但若用两点间距离平方相等则会引入二次方程，计算量偏大。
方法二 · 斜率 $k = \pm 1$ 特殊秒杀法
当对称轴斜率 $k = 1$ 或 $k = -1$（即 $x, y$ 系数绝对值相等，形如 $x \pm y + m = 0$）时，无需列方程组，直接反解换元！
$$\text{由 } x - y + m = 0 \implies \begin{cases} a = y_0 - m \\ b = x_0 + m \end{cases}$$
🔥 口诀： 把点 $(x_0, y_0)$ 代入由直线方程反解出的 $x = \dots$ 得新横坐标 $a$，代入 $y = \dots$ 得新纵坐标 $b$！（仅限 $k = \pm 1$ 或水平/铅垂线）
方法三 · 一般直线对称点秒杀公式
任意点 $P(x_0, y_0)$ 关于一般直线 $Ax+By+C=0$ 的对称点 $P'(a, b)$ 统一公式（选择填空提速利器）：
$$\begin{cases} a = x_0 - 2A \cdot \dfrac{Ax_0 + By_0 + C}{A^2 + B^2} \\[8pt] b = y_0 - 2B \cdot \dfrac{Ax_0 + By_0 + C}{A^2 + B^2} \end{cases}$$
💡 怎么记？ 先算核心比例因子 $\lambda = \dfrac{Ax_0+By_0+C}{A^2+B^2}$，则对称点就是 $(x_0 - 2A\lambda,\; y_0 - 2B\lambda)$，垂足中点就是 $(x_0 - A\lambda,\; y_0 - B\lambda)$。

04 · 例题规范解答与方法对比

一题两解：考场大题规范写法 vs 选填秒杀公式

第一步：提炼原圆信息，设对称圆心

由圆 $C: (x+2)^2 + (y-6)^2 = 1$ 知，原圆心为 $C(-2, 6)$，半径 $r = 1$。
设圆心 $C(-2, 6)$ 关于直线 $l: 3x - 4y + 5 = 0$（斜率 $k_l = \dfrac{3}{4}$）的对称点为 $C'(a, b)$。

第二步：由“一平二垂”列出方程组

线段 $CC'$ 的中点为 $M\left(\dfrac{a-2}{2}, \dfrac{b+6}{2}\right)$，由中点在直线 $l$ 上且 $CC' \perp l$，得：

$$\begin{cases} 3\cdot\dfrac{a-2}{2} - 4\cdot\dfrac{b+6}{2} + 5 = 0 & \text{①（中点在对称轴上）} \\[10pt] \dfrac{b-6}{a+2} \cdot \dfrac{3}{4} = -1 & \text{②（连线与对称轴垂直）} \end{cases}$$
💡 基础薄弱同学点此查看：详细化简与联立消元步骤

Step 1：先将 ①、② 两式去分母化为整式方程

由 ① 两边同乘 $2$：$3(a-2) - 4(b+6) + 10 = 0 \implies 3a - 4b - 20 = 0 \quad \text{③}$
由 ② 交叉相乘：$3(b-6) = -4(a+2) \implies 4a + 3b - 10 = 0 \quad \text{④}$

Step 2：加减消元法消去 $b$

$\text{③}\times 3 + \text{④}\times 4$ 得：$(9a - 12b - 60) + (16a + 12b - 40) = 0$
$$25a - 100 = 0 \implies a = 4$$

Step 3：回代求 $b$

将 $a = 4$ 代入 ④：$4\times 4 + 3b - 10 = 0 \implies 3b = -6 \implies b = -2$

第三步：得出对称圆心，写出圆的方程

联立 ①② 解得 $\begin{cases} a = 4 \\ b = -2 \end{cases}$，故对称圆心为 $C'(4, -2)$，又半径 $r' = r = 1$。

✅ 最终答案： 所求对称圆的方程为 $(x - 4)^2 + (y + 2)^2 = 1$。

第一步：计算对称点公式的核心比例因子 $\lambda$

对于原圆心 $C(x_0, y_0) = (-2, 6)$ 与直线 $3x - 4y + 5 = 0$（其中 $A=3, B=-4, C=5$）：

$$\lambda = \frac{Ax_0 + By_0 + C}{A^2 + B^2} = \frac{3\times(-2) + (-4)\times 6 + 5}{3^2 + (-4)^2} = \frac{-6 - 24 + 5}{25} = \frac{-25}{25} = -1$$

第二步：直接代入对称点公式

$$\begin{cases} a = x_0 - 2A\lambda = -2 - 2\times 3\times(-1) = -2 + 6 = 4 \\[8pt] b = y_0 - 2B\lambda = 6 - 2\times(-4)\times(-1) = 6 - 8 = -2 \end{cases}$$
✅ 秒杀结论： 对称圆心为 $C'(4, -2)$，半径不变仍为 $1$，故方程为 $(x - 4)^2 + (y + 2)^2 = 1$。
05 · 梯度变式训练

变式 1 · 斜率 $k = 1$ 的特殊对称轴（反解换元秒杀）

已知圆 $C_1: (x + 1)^2 + (y - 3)^2 = 4$ 与圆 $C_2$ 关于直线 $l: x - y + 2 = 0$ 对称，求圆 $C_2$ 的标准方程。

📐 思考后点此展开：几何辅助图
📝 查看完整解析与答案

【解析】 原圆心为 $C_1(-1, 3)$，半径 $r = 2$。
因为对称轴 $l: x - y + 2 = 0$ 的斜率 $k = 1$，直接利用反解换元法：

$$\text{由 } x - y + 2 = 0 \implies \begin{cases} x = y - 2 \\ y = x + 2 \end{cases}$$

将 $C_1(-1, 3)$ 的坐标代入右端，直接得对称圆心 $C_2(a, b)$：

$$\begin{cases} a = y_1 - 2 = 3 - 2 = 1 \\ b = x_1 + 2 = -1 + 2 = 1 \end{cases} \implies C_2(1, 1)$$
✅ 答案： 圆 $C_2$ 的标准方程为 $(x - 1)^2 + (y - 1)^2 = 4$。
变式 2 · 一般方程下的圆关于直线对称

已知圆 $C: x^2 + y^2 - 4x + 2y + 1 = 0$，求圆 $C$ 关于直线 $l: 2x - y + 1 = 0$ 对称的圆的标准方程。

📐 思考后点此展开：几何辅助图
📝 查看完整解析与答案

Step 1：先配方求原圆心与半径
将 $x^2 + y^2 - 4x + 2y + 1 = 0$ 配方得 $(x-2)^2 + (y+1)^2 = 4$，故圆心 $C(2, -1)$，半径 $r = 2$。

Step 2：求 $C(2, -1)$ 关于 $2x - y + 1 = 0$ 的对称点 $C'(a, b)$

$$\begin{cases} 2\cdot\dfrac{a+2}{2} - \dfrac{b-1}{2} + 1 = 0 \\[8pt] \dfrac{b+1}{a-2} \cdot 2 = -1 \end{cases} \implies \begin{cases} 2a - b + 7 = 0 \\ a + 2b = 0 \end{cases}$$

由第二式得 $a = -2b$，代入第一式得 $-5b + 7 = 0 \implies b = \dfrac{7}{5}$，进而 $a = -\dfrac{14}{5}$。

✅ 答案： $\left(x + \dfrac{14}{5}\right)^2 + \left(y - \dfrac{7}{5}\right)^2 = 4$。
变式 3 · 逆向综合：由对称关系求参数与公共弦长

已知圆 $C_1: (x - 1)^2 + (y + 2)^2 = 9$ 与圆 $C_2: (x + 3)^2 + (y - 2)^2 = 9$ 关于直线 $l$ 对称。
（1）求直线 $l$ 的方程；
（2）求圆 $C_1$ 与圆 $C_2$ 相交所得公共弦的长度。

📐 思考后点此展开：几何辅助图
📝 查看完整解析与答案

（1）求对称轴 $l$（即线段 $C_1C_2$ 的垂直平分线）：
由题知 $C_1(1, -2)$，$C_2(-3, 2)$，则线段 $C_1C_2$ 的中点为 $M(-1, 0)$。
又 $k_{C_1C_2} = \dfrac{2 - (-2)}{-3 - 1} = -1$，故对称轴斜率 $k_l = 1$。
由点斜式得直线 $l: y - 0 = 1\cdot(x + 1)$，即 $x - y + 1 = 0$。

（2）求公共弦长（对称轴即公共弦所在直线！）：
两等圆关于直线 $l$ 对称，若两圆相交，则公共弦所在直线正是对称轴 $l: x - y + 1 = 0$。
圆心 $C_1(1, -2)$ 到直线 $l$ 的弦心距为：

$$d = |C_1M| = \frac{|1 - (-2) + 1|}{\sqrt{1^2 + (-1)^2}} = \frac{4}{\sqrt{2}} = 2\sqrt{2}$$

由弦长公式 $L = 2\sqrt{r^2 - d^2} = 2\sqrt{9 - (2\sqrt{2})^2} = 2\sqrt{9 - 8} = 2$。

✅ 答案： （1）直线 $l$ 的方程为 $x - y + 1 = 0$；（2）公共弦长为 $2$。
