解析几何 · 椭圆方程、弦长公式与等腰三角形核心知识点锦囊

1. 椭圆基本几何量与离心率

• 标准方程（焦点在 x 轴）：[[frac:x[[sup:2]]|a[[sup:2]]]] + [[frac:y[[sup:2]]|b[[sup:2]]]] = 1 (a > b > 0)
• 核心关系：a[[sup:2]] = b[[sup:2]] + c[[sup:2]]，右焦点 (c, 0)
• 离心率定义：e = [[frac:c|a]] ∈ (0, 1)，已知 c 和 e 时直接用 a = [[frac:c|e]] 求 a。

2. 等腰三角形“三线合一”几何转化

• 核心结论：若 △PAB 以 AB 为底边、P 为顶点构成等腰三角形，设 M 为底边 AB 的中点，则中线 PM 垂直于底边 AB（PM ⊥ AB）！
• 斜率翻译：当直线 AB 与 PM 斜率均存在且不为 0 时，k[[sub:PM]] · k[[sub:AB]] = -1（本题 k[[sub:AB]] = 1，故 k[[sub:PM]] = -1）。

3. 直线与椭圆联立韦达定理模板

• 设直线 l : y = kx + m 与椭圆联立消去 y，整理为 Ax[[sup:2]] + Bx + C = 0 (A ≠ 0)：
  ① 判别式：Δ = B[[sup:2]] - 4AC > 0（确定参数 m 的取值范围）；
  ② 韦达定理：x[[sub:1]] + x[[sub:2]] = -[[frac:B|A]]，x[[sub:1]]x[[sub:2]] = [[frac:C|A]]；
  ③ 中点坐标：x[[sub:0]] = [[frac:x[[sub:1]] + x[[sub:2]]|2]]，y[[sub:0]] = kx[[sub:0]] + m。

4. 弦长公式与点到直线距离公式

• 弦长公式：|AB| = [[sqrt:1 + k[[sup:2]]]] · |x[[sub:1]] - x[[sub:2]]| = [[sqrt:1 + k[[sup:2]]]] · [[sqrt:(x[[sub:1]] + x[[sub:2]])[[sup:2]] - 4x[[sub:1]]x[[sub:2]]]]
• 点到直线距离：点 P(x[[sub:P]], y[[sub:P]]) 到直线 Ax + By + C = 0 的距离 d = [[frac:|Ax[[sub:P]] + By[[sub:P]] + C|| [[sqrt:A[[sup:2]] + B[[sup:2]]]]]]
• 面积公式：S[[sub:△PAB]] = [[frac:1|2]] |AB| · d（或 [[frac:1|2]] |AB| · |PM|）。
