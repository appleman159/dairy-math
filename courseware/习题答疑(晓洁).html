01 · 核心问题与双解题视角

不背死公式：双平行虚线转化 + 抓“奇数个点”相切临界由奇推偶

【核心例题】已知圆 $C: (x - 2)^2 + (y + 1)^2 = 4$，直线 $l: x - y + m = 0$。若圆 $C$ 上恰有 $4$ 个点到直线 $l$ 的距离等于 $1$，求实数 $m$ 的取值范围。
视角一 · 几何直观转化
双平行虚线走廊法

平面内到直线 $l$ 的距离等于定值 $h$（本题 $h=1$）的点的轨迹，是位于 $l$ 两侧、平行于 $l$ 且相距为 $h$ 的两条异色平行虚线： 虚线 $l_1$ 与 虚线 $l_2$。

核心等价：圆 $C$ 上到 $l$ 距离为 $h$ 的点的个数 $\Longleftrightarrow$ 两条平行虚线 $l_1, l_2$ 与圆 $C$ 的交点总数（$0 \sim 4$ 个）！

视角二 · 重点推荐（由奇推偶）
奇数点相切临界法（抓 $d$ 与 $r$ 关系）

为什么会出现奇数个点（$1$ 个或 $3$ 个）？因为必有一条平行虚线恰好与圆相切！先抓这两个特殊临界点：

• 临界 ①（恰有 $1$ 个点·外切）：近侧虚线与圆外切，远侧相离 $\implies \boldsymbol{d = r + h}$（本题 $d = 2+1 = 3$）。

• 临界 ②（恰有 $3$ 个点·内切）：近侧虚线交圆 $2$ 点，远侧虚线与圆内侧相切 $1$ 点 $\implies \boldsymbol{d = r - h}$（本题 $d = 2-1 = 1$）。

🎯 由奇推偶：用两个“奇数点相切临界值”切分 $d$ 的数轴，偶数点范围一目了然！ （设 $r > h$，点击下方画板可动态验证）

03 · 主例题双视角规范解答

两种视角殊途同归，基础薄弱同学可点开中间折叠框学习不等式化简

1

求圆心、半径，并写出圆心距 $d$ 的表达式

由圆 $C: (x - 2)^2 + (y + 1)^2 = 4$ 得圆心 $C(2, -1)$，半径 $r = 2$。题目要求圆上点到直线 $l: x - y + m = 0$ 的距离为定值 $h = 1$。

由点到直线的距离公式，圆心 $C(2, -1)$ 到直线 $l$ 的距离 $d$ 为：

$$d = \frac{|2 - (-1) + m|}{\sqrt{1^2 + (-1)^2}} = \frac{|m + 3|}{\sqrt{2}}$$
2

先找“奇数个点”的相切临界状态，再由奇推偶确定 $4$ 个点的范围

结合图形分析圆心距 $d$ 与半径 $r = 2$、定距 $h = 1$ 的关系：

• 当恰有 $3$ 个点满足要求（临界内切）时，$d = r - h = 2 - 1 = 1$；
• 当恰有 $1$ 个点满足要求（临界外切）时，$d = r + h = 2 + 1 = 3$。

要使圆上恰有 $4$ 个点（偶数范围）到直线 $l$ 的距离等于 $1$，直线 $l$ 必须比“$3$ 个点的临界位置”更靠近圆心，故圆心距 $d$ 需满足：

$$0 \le d < r - 1 \implies \frac{|m + 3|}{\sqrt{2}} < 1$$
3

解绝对值不等式得出 $m$ 的范围

💡 基础薄弱同学点此展开：绝对值不等式详细化简过程 查看详细演算
Step 1：不等式两边同乘分母 $\sqrt{2}$
$$\frac{|m + 3|}{\sqrt{2}} < 1 \implies |m + 3| < \sqrt{2}$$
Step 2：利用 $|X| < a \Longleftrightarrow -a < X < a$ 拆开绝对值
$$-\sqrt{2} < m + 3 < \sqrt{2}$$
Step 3：不等式三边同时减去 $3$ 解出 $m$
$$-3 - \sqrt{2} < m < -3 + \sqrt{2}$$

解得 $-3 - \sqrt{2} < m < -3 + \sqrt{2}$。

1

添画两条平行虚线，转化为直线与圆相交问题

由圆 $C: (x - 2)^2 + (y + 1)^2 = 4$ 知圆心 $C(2, -1)$，半径 $r = 2$。

在直线 $l: x - y + m = 0$ 两侧各作一条距离为 $1$ 的平行虚线 $l_1, l_2$。圆 $C$ 上恰有 $4$ 个点到 $l$ 的距离为 $1$，等价于两条平行虚线 $l_1, l_2$ 均与圆 $C$ 相交（各产生 $2$ 个交点）。

设圆心 $C$ 到主直线 $l$ 的距离为 $d$，则较远的一条平行虚线到圆心的距离为 $d + 1$。要使两条虚线都穿过圆内部，只需较远虚线到圆心的距离小于半径 $r$：

$$d + 1 < r \implies d + 1 < 2 \implies d < 1$$
2

代入点到直线距离公式求解 $m$

$$d = \frac{|2 - (-1) + m|}{\sqrt{1^2 + (-1)^2}} = \frac{|m + 3|}{\sqrt{2}} < 1$$
💡 基础薄弱同学点此展开：绝对值不等式详细化简过程 查看详细演算
Step 1：去分母
两边同乘 $\sqrt{2}$ 得 $|m + 3| < \sqrt{2}$。
Step 2：去绝对值并移项
$$-\sqrt{2} < m + 3 < \sqrt{2} \implies -3 - \sqrt{2} < m < -3 + \sqrt{2}$$

解得 $-3 - \sqrt{2} < m < -3 + \sqrt{2}$。

✅ 最终答案
实数 $m$ 的取值范围是 $(-3 - \sqrt{2},\, -3 + \sqrt{2})$。

变式训练 1 模型一：圆定 + 线定 · 逆向求点的个数
已知圆 $C: (x + 1)^2 + (y - 2)^2 = 9$，直线 $l: 3x + 4y - 15 = 0$。则圆 $C$ 上到直线 $l$ 的距离等于 $1$ 的点共有（　）
A. $1$ 个
B. $2$ 个
C. $3$ 个
D. $4$ 个
📐 思考后点此展开：几何辅助图（含双平行虚线与 $d, r$ 关系） 查看配图
圆心距 $d = 2$，恰满足 $d = r - h = 3 - 1 = 2$（即 $3$ 个点的奇数相切临界状态）
📝 点此查看：完整解析与答案（奇数临界法 & 平行线法双解） 展开解析

解：由圆 $C: (x+1)^2 + (y-2)^2 = 9$ 得圆心 $C(-1, 2)$，半径 $r = 3$，定距 $h = 1$。

① 先求圆心 $C(-1, 2)$ 到直线 $l: 3x + 4y - 15 = 0$ 的距离 $d$：

$$d = \frac{|3\times(-1) + 4\times 2 - 15|}{\sqrt{3^2 + 4^2}} = \frac{|-10|}{5} = 2$$

② 视角一（奇数点相切临界法）：
计算两个奇数点临界值：$3$ 个点临界为 $r - h = 3 - 1 = 2$；$1$ 个点临界为 $r + h = 3 + 1 = 4$。因为算出的 $d = 2$ 恰好等于 $r - h$，所以正好处于恰有 $3$ 个点的临界内切状态！

③ 视角二（双平行虚线法）：
近侧平行虚线 $l_1$ 到圆心距离 $d_1 = d - 1 = 1 < r$（相交，交 $2$ 点）；远侧平行虚线 $l_2$ 到圆心距离 $d_2 = d + 1 = 3 = r$（相切，切 $1$ 点）。

综上所述，圆上满足条件的点共有 $2 + 1 = 3$ 个，故选 C。

变式训练 2 · 2025年高考真题 模型二：线定 + 圆动 · 已知点数求半径范围
（2025·高考真题）若圆 $x^2 + (y + 2)^2 = r^2\ (r > 0)$ 上到直线 $y = \sqrt{3}x + 2$ 的距离为 $1$ 的点有且仅有 $2$ 个，则 $r$ 的取值范围是（　）
A. $(0, 1)$
B. $(1, 3)$
C. $(3, +\infty)$
D. $(0, +\infty)$
📐 思考后点此展开：几何辅助图（含双平行虚线与 $d, r$ 关系） 查看配图
圆心距 $d = 2$，$1$ 个点的外切临界半径为 $r_1 = d - 1 = 1$，$3$ 个点的内切临界半径为 $r_2 = d + 1 = 3$，故 $2$ 个点夹在 $(1, 3)$ 之间
📝 点此查看：完整解析与答案（奇数临界法 & 平行线法双解） 展开解析

解：由圆的方程 $x^2 + (y + 2)^2 = r^2$ 得定圆心 $C(0, -2)$，半径为 $r > 0$；将直线化为一般式：$\sqrt{3}x - y + 2 = 0$。

① 求圆心 $C(0, -2)$ 到直线 $\sqrt{3}x - y + 2 = 0$ 的距离 $d$：

$$d = \frac{|\sqrt{3}\times 0 - (-2) + 2|}{\sqrt{(\sqrt{3})^2 + (-1)^2}} = \frac{4}{2} = 2$$

② 视角一（奇数点相切临界法）：
想象圆的半径 $r$ 从 $0$ 开始逐渐变大：
• 当恰有 $1$ 个点（圆刚触碰到近侧虚线外切）时，$d = r + 1 \implies r = d - 1 = 2 - 1 = 1$；
• 当恰有 $3$ 个点（圆刚触碰到远侧虚线内切）时，$d = r - 1 \implies r = d + 1 = 2 + 1 = 3$。
由奇推偶可知，要使圆上有且仅有 $2$ 个点满足条件，半径 $r$ 必介于这两个奇数点临界值之间，即 $1 < r < 3$。

③ 视角二（双平行虚线法）：
近侧平行虚线到圆心距离为 $2 - 1 = 1$，远侧平行虚线到圆心距离为 $2 + 1 = 3$。恰有 $2$ 个交点即圆与近轨相交且与远轨相离，故 $1 < r < 3$。

因此 $r$ 的取值范围是 $(1, 3)$，故选 B。

变式训练 3 模型三：圆定 + 线动 · 先求奇数临界(3点)再推偶数范围(2点)
已知圆 $C: (x - 1)^2 + (y - 2)^2 = 5$，直线 $l: 2x - y + c = 0$。
（1）若圆 $C$ 上恰有 $3$ 个点 到直线 $l$ 的距离为 $\dfrac{\sqrt{5}}{5}$，求实数 $c$ 的值；
（2）若圆 $C$ 上恰有 $2$ 个点 到直线 $l$ 的距离为 $\dfrac{\sqrt{5}}{5}$，求实数 $c$ 的取值范围。
📐 思考后点此展开：几何辅助图（含双平行虚线与 $d, r$ 关系） 查看配图
第（1）问先求 $3$ 个点的奇数临界：$d = r - h = \sqrt{5} - \frac{\sqrt{5}}{5} = \frac{4\sqrt{5}}{5}$；第（2）问再看 $1$ 个点临界 $d = r + h = \frac{6\sqrt{5}}{5}$，夹在两临界值之间即为 $2$ 个点！
📝 点此查看：完整解析与答案（深刻体会“由奇推偶”的威力） 展开解析

解：由圆 $C: (x - 1)^2 + (y - 2)^2 = 5$ 知圆心 $C(1, 2)$，半径 $r = \sqrt{5}$，定距 $h = \dfrac{\sqrt{5}}{5}$。

圆心 $C(1, 2)$ 到直线 $l: 2x - y + c = 0$ 的距离为：

$$d = \frac{|2\times 1 - 2 + c|}{\sqrt{2^2 + (-1)^2}} = \frac{|c|}{\sqrt{5}}$$

（1）求恰有 $3$ 个点（奇数点内切临界）时 $c$ 的值：

当圆上恰有 $3$ 个点到直线 $l$ 的距离为 $h$ 时，必有一条平行虚线与圆相交（$2$点）、另一条平行虚线与圆相切（$1$点），此时圆心距 $d$ 满足：

$$d = r - h = \sqrt{5} - \frac{\sqrt{5}}{5} = \frac{4\sqrt{5}}{5}$$

代入 $d = \dfrac{|c|}{\sqrt{5}}$ 得：

$$\frac{|c|}{\sqrt{5}} = \frac{4\sqrt{5}}{5} \implies |c| = 4 \implies \boldsymbol{c = 4 \text{ 或 } c = -4}$$

（2）由奇推偶，求恰有 $2$ 个点（偶数点区间）时 $c$ 的范围：

先找另一个奇数临界态——当圆上恰有 $1$ 个点（外切临界）时：

$$d = r + h = \sqrt{5} + \frac{\sqrt{5}}{5} = \frac{6\sqrt{5}}{5} \implies \frac{|c|}{\sqrt{5}} = \frac{6\sqrt{5}}{5} \implies |c| = 6$$

要使圆上恰有 $2$ 个点满足条件，圆心距 $d$ 必须夹在“$3$ 个点临界”与“$1$ 个点临界”之间：

$$r - h < d < r + h \implies \frac{4\sqrt{5}}{5} < \frac{|c|}{\sqrt{5}} < \frac{6\sqrt{5}}{5} \implies 4 < |c| < 6$$

解得实数 $c$ 的取值范围是 $(-6, -4) \cup (4, 6)$。

05 · 考场实战三步通法总结

记住“先奇后偶”三步口诀，无需死背任何复杂公式

STEP 01 · 算距离
写出圆心距 $d$ 与半径 $r$
将直线化为一般式 $Ax+By+C=0$，用点到直线距离公式表示出圆心到主直线的距离 $d$，明确圆半径 $r$ 与给定距离 $h$。
STEP 02 · 定奇数临界
找 $1$ 点与 $3$ 点的相切态
在主直线两侧画相距为 $h$ 的平行虚线：恰有 $3$ 点（远轨内切）对应 $\boldsymbol{d = r - h}$；恰有 $1$ 点（近轨外切）对应 $\boldsymbol{d = r + h}$。
STEP 03 · 由奇推偶
按数轴切分偶数点区间
用两个奇数临界点把 $d$ 的范围切开：$0 \le d < r-h$ 为 $4$ 个点，$r-h < d < r+h$ 为 $2$ 个点，$d > r+h$ 为 $0$ 个点！
