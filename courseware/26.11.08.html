📚 二、做题前必背的 5 大核心知识点（基础薄弱必看）
知识 1圆的标准方程与圆上点的【参数坐标形式】
① 读出圆心和半径：
圆的标准方程为 (x − a)2 + (y − b)2 = R2，其圆心为 C(a, b)，半径为 R。
• 本题中：(x − 2)2 + (y − 1)2 = 1，所以圆心 C(2, 1)，半径 R = 1。

② 什么是圆上点的参数坐标？（为什么能这么设？）
因为 cos2θ + sin2θ = 1 恒成立！对于圆 (x − a)2 + (y − b)2 = R2，我们可以令：
x − a = Rcosθ，  y − b = Rsinθ  （其中参数 θ ∈ [0, 2π) 为旋转角）
移项后，圆上任意一点 P(x, y) 的坐标都可以用只含一个角度 θ 的参数坐标表示为：
x = a + Rcosθ
y = b + Rsinθ
• 本题直接套用：圆心 (2, 1)、半径 R = 1，故圆上点 P 的参数坐标为：
  x = 2 + cosθ，  y = 1 + sinθ。
• 巨大好处：把原本两个未知数 x, y 变成只有一个角度变量 θ，直接转化为三角函数求最值！
知识 2点到直线的距离公式 & 直线与圆相切条件
• 点到直线距离公式：点 C(x0, y0) 到直线 Ax + By + C = 0 的距离为：
d = |Ax0 + By0 + C|A2 + B2
• 直线与圆的位置关系（临界极值条件）：
  1. 直线与圆有公共点（相交或相切） ⇔ 圆心到直线的距离 d ≤ R；
  2. 直线与圆相切（取最大/最小值的临界位置） ⇔ 圆心到直线的距离 d = R。
知识 3三角函数辅助角公式（合一变形求最值）
形如 asinθ + bcosθ 的式子，可以合成为一个正弦函数：
asinθ + bcosθ = a2 + b2 sin(θ + φ)  ∈  [−a2 + b2,  a2 + b2]
• 最常用的两个特例（必背）：
  ① sinθ + cosθ = 2sin(θ + π4)，最大值为 2，最小值为 −2；
  ② 2cosθ + sinθ = 22 + 12sin(θ + φ) = 5sin(θ + φ)，最大值为 5，最小值为 −5。
知识 4圆上动点 P(x, y) 三大代数式的【几何意义翻译表】
看到以下含有 x, y 的式子，脑海中要立刻翻译出它的几何图形：
  • ① 分式型 yx（或 y − bx − a）→ 【斜率模型】
    写成 k = y − 0x − 0，表示圆上动点 P(x, y) 与原点 O(0, 0) 连线的斜率 k。当直线 OP 与圆相切时，斜率 k 取得最大值和最小值！
  • ② 一次线性型 x + y（或 Ax + By）→ 【截距模型】
    设 x + y = t，变形为 y = −x + t，表示斜率为 −1 的平行直线系在 y 轴上的纵截距 t。当直线平移到与圆相切时，截距 t 取得最大和最小值！
  • ③ 二次平方和型 x2 + y2（或 (x − a)2 + (y − b)2）→ 【距离平方模型】
    因为点 P(x, y) 到原点 O(0, 0) 的距离为 |OP| = (x − 0)2 + (y − 0)2 = x2 + y2，所以 x2 + y2 = |OP|2 是动点到原点距离的平方（千万注意：是距离的平方，不是距离本身！）。先用“圆心距 |OC| ± R”算出 |OP| 的最值，最后平方即可！

🔍 四、第 (1) 题详解：求 yx 的最值（几何意义：斜率 + 相切）
核心方法利用斜率的几何意义，直线与圆相切时取最值
第一步（识别几何意义，转化为直线方程）：
令 k = yx = y − 0x − 0，则 k 表示圆上的动点 P(x, y) 与坐标原点 O(0, 0) 连线的斜率。
将 k = yx 变形为过原点的直线方程（一般式）：
y = kx  ⇔  kx − y = 0
第二步（利用直线与圆有公共点列不等式，相切时取极值）：
因为点 P(x, y) 既在直线 kx − y = 0 上，又在圆 (x − 2)2 + (y − 1)2 = 1 上，说明直线与圆必有公共点（相交或相切）！
当直线绕原点旋转到与圆相切时，斜率 k 达到最大和最小。
由“圆心 C(2, 1) 到直线 kx − y = 0 的距离 d ≤ R（相切时 d = R = 1）”得：
d = |2k − 1|k2 + (−1)2 ≤ 1
第三步（两边平方解关于 k 的方程/不等式）：
将分母乘过去：|2k − 1| ≤ k2 + 1，两边同时平方（两边均非负，可直接平方）：
(2k − 1)2 ≤ k2 + 1
4k2 − 4k + 1 ≤ k2 + 1
3k2 − 4k ≤ 0  ⇔  k(3k − 4) ≤ 0
解得：0 ≤ k ≤ 43。
• 当下切线与 x 轴重合（切点为 (2, 0)）时，斜率最小：kmin = 0；
• 当上切线与圆相切时，斜率最大：kmax = 43。
🔍 五、第 (2) 题双解：求 x + y 的最值
方法一圆的参数坐标 + 三角函数辅助角公式（无脑代入通法）
第一步（写出圆上点 P 的参数坐标）：
由圆方程 (x − 2)2 + (y − 1)2 = 1，设点 P 的参数坐标为：
x = 2 + cosθ，  y = 1 + sinθ  （θ ∈ [0, 2π)）
第二步（代入 x + y 并用辅助角公式化简）：
x + y = (2 + cosθ) + (1 + sinθ)
= 3 + (sinθ + cosθ)
= 3 + 2sin(θ + π4)
第三步（利用正弦函数的有界性求最值）：
因为 sin(θ + π4) ∈ [−1, 1]：
• 当 sin(θ + π4) = 1（即 θ = π4 = 45°）时，最大值为 3 + 2；
• 当 sin(θ + π4) = −1（即 θ = 5π4 = 225°）时，最小值为 3 − 2。
方法二几何意义（直线截距法：平行线与圆相切时截距取极值）
第一步（设 x + y = t 转化为直线截距）：
令 x + y = t，移项得直线一般式方程：
x + y − t = 0  （即 y = −x + t，其中 t 为直线在 y 轴上的纵截距）
第二步（直线与圆相切/相交条件 d ≤ R）：
直线 x + y − t = 0 与圆有公共点，故圆心 C(2, 1) 到该直线的距离 d ≤ R = 1：
d = |2 + 1 − t|12 + 12 = |3 − t|2 ≤ 1
第三步（解绝对值不等式）：
|t − 3| ≤ 2  ⇔  −2 ≤ t − 3 ≤ 2  ⇔  3 − 2 ≤ t ≤ 3 + 2
故 x + y 的最大值为 3 + 2，最小值为 3 − 2。
🔍 六、第 (3) 题双解：求 x2 + y2 的最值
方法一圆的参数坐标 + 三角函数辅助角公式
第一步（代入参数坐标 x = 2 + cosθ, y = 1 + sinθ 展开）：
x2 + y2 = (2 + cosθ)2 + (1 + sinθ)2
= (4 + 4cosθ + cos2θ) + (1 + 2sinθ + sin2θ)
第二步（利用 cos2θ + sin2θ = 1 合并化简）：
x2 + y2 = 4 + 1 + (cos2θ + sin2θ) + 4cosθ + 2sinθ
= 6 + 2(2cosθ + sinθ)
第三步（辅助角公式求最值）：
由辅助角公式，提取系数平方和开根号 22 + 12 = 5：
2cosθ + sinθ = 5sin(θ + φ)  ∈  [−5,  5]
⇒ x2 + y2 = 6 + 25sin(θ + φ)
• 当 sin(θ + φ) = 1 时，最大值为 6 + 25；
• 当 sin(θ + φ) = −1 时，最小值为 6 − 25。
方法二几何意义（动点到原点距离的平方：穿心线法则）
第一步（识别几何意义：距离的平方！）：
因为圆上动点 P(x, y) 到原点 O(0, 0) 的距离为 |OP| = x2 + y2，所以：
x2 + y2 = |OP|2（即动点 P 到原点 O 距离的平方）
第二步（算圆心距 |OC|，求距离 |OP| 的最值）：
圆心 C(2, 1) 到原点 O(0, 0) 的距离（圆心距）为：
|OC| = (2 − 0)2 + (1 − 0)2 = 5
已知圆的半径 R = 1，连接 OC 穿圆而过：
• 最短距离：|OP|min = |OC| − R = 5 − 1；
• 最长距离：|OP|max = |OC| + R = 5 + 1。

第三步（别忘了最后要平方！）：
• (x2 + y2)min = (|OP|min)2 = (5 − 1)2 = 5 − 25 + 1 = 6 − 25
• (x2 + y2)max = (|OP|max)2 = (5 + 1)2 = 5 + 25 + 1 = 6 + 25
⚠️ 第 (3) 题高频易错警告：
90% 做错的同学都是算出了 5 + 1 和 5 − 1 就直接填上去了！
一定要看清题目问的是 x2 + y2（没有根号，是距离的平方），还是 x2 + y2（有根号，是距离本身）！如果没有根号，算完 d ± R 后必须平方！
🚀 七、举一反三 · 趁热打铁自测题
【变式训练】已知实数 x, y 满足方程 (x − 3)2 + (y − 4)2 = 1，求：
(1) yx 的最值；   (2) x − y 的最值；   (3) x2 + y2 的最值。
【先找圆心和半径 + 参数坐标】：
圆心为 C(3, 4)，半径 R = 1；圆上点的参数坐标为 x = 3 + cosθ, y = 4 + sinθ。

(1) 求 yx 的最值（斜率相切法）：
设 yx = k ⇔ kx − y = 0。由圆心 C(3, 4) 到直线的距离 d ≤ 1 得：
|3k − 4|k2 + 1 ≤ 1 ⇔ (3k − 4)2 ≤ k2 + 1 ⇔ 8k2 − 24k + 15 ≤ 0
由求根公式得：kmax = 12 + 248 = 6 + 64，kmin = 6 − 64。

(2) 求 x − y 的最值（双解）：
• 方法一（参数坐标法）：x − y = (3 + cosθ) − (4 + sinθ) = −1 + (cosθ − sinθ) = −1 + 2cos(θ + π4)。
  故最大值为 −1 + 2，最小值为 −1 − 2。
• 方法二（截距法）：设 x − y = t ⇔ x − y − t = 0，由 d = |3 − 4 − t|2 ≤ 1 得 |t + 1| ≤ 2，同样解得 [−1 − 2, −1 + 2]。

(3) 求 x2 + y2 的最值（双解）：
• 方法一（参数坐标法）：x2 + y2 = (3 + cosθ)2 + (4 + sinθ)2 = 9 + 16 + 1 + 2(3cosθ + 4sinθ) = 26 + 2 × 5sin(θ + φ) = 26 + 10sin(θ + φ)。
  故最大值为 26 + 10 = 36，最小值为 26 − 10 = 16。
• 方法二（距离平方法）：圆心距 |OC| = 32 + 42 = 5，半径 R = 1。
  距离 |OP|max = 5 + 1 = 6，|OP|min = 5 − 1 = 4。
  平方后得：(x2 + y2)max = 62 = 36，(x2 + y2)min = 42 = 16！
