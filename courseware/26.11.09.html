复数模的最值与几何意义
主讲：Z老师 ｜ 直接用手指拖动圆上的点 P，直观秒懂最值原理
📌 一、原题再现（先点击选项测一测）
1. 已知复数 z 满足 |z| = 1，则 |z − 1 − i| 的取值范围是（    ）
📚 二、本题必备核心知识点梳理（建议熟记）
考点 1复数的代数形式与复平面点的对应
任意复数都可设为代数形式 z = x + yi（其中 x, y ∈ R）：
  • 实部为 x（对应横坐标），虚部为 y（对应纵坐标，注意虚部不含 i）。
  • 一一对应关系：复数 z = x + yi ↔ 复平面内的点 P(x, y) ↔ 平面向量 OP = (x, y)。
  • 例如：复数 1 + i 对应定点 A(1, 1)；复数 2 − 3i 对应定点 (2, −3)。
考点 2复数模的计算公式与几何意义
① 单个复数的模 |z|：若 z = x + yi，由勾股定理得：
|z| = |x + yi| = x2 + y2（即实部平方 + 虚部平方再开方）
• 几何意义：表示复平面内的点 P(x, y) 到坐标原点 O(0, 0) 的距离 |OP|。

② 两个复数差的模 |z1 − z2|（高频重点！）：
设 z = x + yi 对应动点 P(x, y)，复数 z0 = a + bi 对应定点 A(a, b)，则：
|z − z0| = |(x − a) + (y − b)i| = (x − a)2 + (y − b)2 = |PA|
• 几何意义：表示复平面上两点 P(x, y) 与 A(a, b) 之间的距离！
• 避坑关键（先提负号化标准差形式）：遇到 |z − 1 − i|，必须先用括号把后面的数括起来写成 |z − (1 + i)|，才能看出定点是 (1, 1) 而不是 (−1, −1)！同理，|z + 2 − i| = |z − (−2 + i)| 对应定点 (−2, 1)。
考点 3复数模的方程与圆的标准方程的转化
我们在解析几何中学过：圆心为 C(a, b)、半径为 R 的圆的标准方程为：
(x − a)2 + (y − b)2 = R2  ⇔  (x − a)2 + (y − b)2 = R
对比复数模长公式，立刻得到复数中的圆轨迹三大结论：
  • 单位圆：|z| = 1 ⇔ x2 + y2 = 1 ⇔ x2 + y2 = 1，表示以原点 O(0,0) 为圆心、半径 R = 1 的圆。
  • 一般圆：|z − (a + bi)| = R ⇔ (x − a)2 + (y − b)2 = R2，表示以 C(a, b) 为圆心、半径为 R 的圆。
考点 4圆上动点到定点距离的最值定理（穿心线法则）
已知圆心为 C、半径为 R 的圆，以及平面内一定点 A，记圆心到定点的距离（圆心距）为 d = |CA|。当动点 P 在圆周上运动时：
• 最短距离：|PA|min = |d − R|（当 P 位于线段 CA 与圆的交点时取得，此时 C, P, A 三点同向共线）
• 最长距离：|PA|max = d + R（当 P 位于线段 AC 延长线与圆的交点时取得，此时 P, C, A 三点反向共线）
口诀记忆：“先算圆心距 d，再加减半径 R；共线穿心取极值，范围闭区间 [d − R, d + R]”。
考点 5复数模的三角不等式（几何意义：三角形两边之和/差）
对于任意两个复数 z1, z2，在复平面内构成三角形（或共线），由“三角形两边之差小于第三边、两边之和大于第三边”恒有：
||z1| − |z2|| ≤ |z1 ± z2| ≤ |z1| + |z2|
• 左边等号在两向量同向（减法）或反向（加法）时取到；右边等号在反向（减法）或同向（加法）时取到。

💡 四、三种方法透彻解析（代数圆方程 + 几何法）
解法一代数坐标法（设 z = x + yi 代入模长公式 + 圆的方程）
第一步（设复数代数形式）：
设复数 z = x + yi（其中 x, y ∈ R），在直角坐标系中对应动点 P(x, y)。

第二步（翻译已知条件 |z| = 1 为圆的方程）：
由复数模长公式 |z| = x2 + y2 = 1，两边平方得：
x2 + y2 = 1
这说明点 P(x, y) 的轨迹是以原点 O(0, 0) 为圆心、半径 R = 1 的圆。

第三步（代入所求模长公式）：
将 z = x + yi 代入所求式子，合并实部与虚部：
|z − 1 − i| = |(x + yi) − 1 − i| = |(x − 1) + (y − 1)i|
= (x − 1)2 + (y − 1)2
第四步（利用两点距离与圆的性质求最值）：
观察发现，式子 (x − 1)2 + (y − 1)2 正好是圆 x2 + y2 = 1 上的动点 P(x, y) 到定点 A(1, 1) 的距离 |PA|！
计算圆心 O(0,0) 到定点 A(1,1) 的圆心距：
d = |OA| = (1 − 0)2 + (1 − 0)2 = 2
因为 d = 2 > R = 1（定点 A 在圆外），根据“圆上动点到定点距离最值结论”：
• 最小值：|PA|min = d − R = 2 − 1
• 最大值：|PA|max = d + R = 2 + 1
故 |z − 1 − i| 的取值范围是 [2 − 1, 2 + 1]，选 A。
解法二复数几何意义直接秒杀法（不设 x, y，考场 10 秒出答案）
1. 看轨迹：|z| = |z − 0| = 1 直接表示复数 z 对应的点 P 在以原点 O(0,0) 为圆心、半径 R = 1 的单位圆上。
2. 看目标：将原式添括号变形为 |z − (1 + i)|，直接表示点 P 到定点 A(1, 1) 的距离。
3. 算圆心距加减半径：d = |OA| = 12 + 12 = 2，直接写出范围 [d − R, d + R] = [2 − 1, 2 + 1]。
解法三纯代数展开 + 均值不等式法（深化代数基本功）
把 x2 + y2 = 1 代入根号内展开：
|z − 1 − i| = (x − 1)2 + (y − 1)2 = (x2 + y2) − 2(x + y) + 2 = 3 − 2(x + y)
只需求出 x + y 的范围即可！由完全平方非负性 (x − y)2 ≥ 0 可得 2xy ≤ x2 + y2，因此：
(x + y)2 = x2 + y2 + 2xy ≤ 2(x2 + y2) = 2  ⇒  −2 ≤ x + y ≤ 2
• 当 x = y = 2 / 2 时，x + y 取最大值 2，原式取最小值 3 − 22 = (2 − 1)2 = 2 − 1；
• 当 x = y = −2 / 2 时，x + y 取最小值 −2，原式取最大值 3 + 22 = (2 + 1)2 = 2 + 1。
⚠️ 常见错误警示：
很多同学看到 |z − 1 − i| 会直接错算成 |z| − |1| − |i| = 1 − 1 − 1 = −1，或者误以为定点是 (−1, −1)。切记：
1. 模长永远非负（|z| ≥ 0），且不能直接把绝对值号拆开分配给每一项；
2. 必须写成标准差形式 |z − z0|，即 |z − (1 + i)|，才能准确找出定点 A(1, 1)！
🚀 五、举一反三 · 变式巩固训练
【变式 1（圆心不在原点）】已知复数 z 满足 |z − 2 − 2i| = 1，求 |z| 的取值范围。
• 设 z = x + yi 化圆方程：条件 |(x − 2) + (y − 2)i| = 1 ⇔ (x − 2)2 + (y − 2)2 = 1，表示以 C(2, 2) 为圆心、半径 R = 1 的圆。
• 看所求目标：|z| = x2 + y2 表示圆上动点 P(x, y) 到原点 O(0,0) 的距离。
• 算圆心距：d = |OC| = 22 + 22 = 8 = 22。
• 结论：取值范围是 [d − R, d + R] = [22 − 1, 22 + 1]。
【变式 2（加号符号陷阱 + 距离平方）】已知复数 z 满足 |z + 1 − 2i| = 2，求 |z − 2 + 2i| 的最小值与最大值。
• 第一步（设 z = x + yi 找圆心与半径）：
  |z + 1 − 2i| = |(x + 1) + (y − 2)i| = 2 ⇔ (x + 1)2 + (y − 2)2 = 4。
  所以动点 P(x, y) 在以 C(−1, 2) 为圆心、半径 R = 2 的圆上。
• 第二步（化所求式子找定点）：
  |z − 2 + 2i| = |(x − 2) + (y + 2)i| = (x − 2)2 + (y − (−2))2，表示动点 P 到定点 A(2, −2) 的距离。
• 第三步（算圆心距 d = |CA|）：
  d = |CA| = (2 − (−1))2 + (−2 − 2)2 = 32 + (−4)2 = 5。
• 结论：
  最小值 = d − R = 5 − 2 = 3；最大值 = d + R = 5 + 2 = 7。
