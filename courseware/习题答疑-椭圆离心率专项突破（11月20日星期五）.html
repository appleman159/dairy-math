1. 椭圆的基本几何量与离心率

• 标准方程（焦点在 x 轴）：[[frac:x[[sup:2]]|a[[sup:2]]]] + [[frac:y[[sup:2]]|b[[sup:2]]]] = 1 (a > b > 0)
• 核心关系：a[[sup:2]] = b[[sup:2]] + c[[sup:2]]，焦距 |F[[sub:1]]F[[sub:2]]| = 2c
• 顶点与焦点：左顶点 A(-a, 0)，右顶点 (a, 0)，左焦点 F[[sub:1]](-c, 0)，右焦点 F[[sub:2]](c, 0)
• 关键距离：|AF[[sub:2]]| = a + c，|AF[[sub:1]]| = a - c
• 离心率定义：e = [[frac:c|a]] ∈ (0, 1)，且 e[[sup:2]] = 1 - [[frac:b[[sup:2]]|a[[sup:2]]]]

2. 赋值法求离心率（学生最易拿分技巧）

• 原理：椭圆离心率 e = [[frac:c|a]] 只与图形形状有关，与大小无关！
• 操作口诀：已知焦距关系时，直接令 |F[[sub:1]]F[[sub:2]]| = 2（即 2c = 2 ⇒ c = 1），所有字母瞬间变成具体数字！
• 配合直角三角形：遇到 120°、60°、45°、30° 特殊角，过动点 P 向 x 轴作垂线 PH，用特殊直角三角形边长比（1 : [[sqrt:3]] : 2）秒出线段长，最后由 |AF[[sub:2]]| = a + c 求出 a。

3. 等腰三角形分类讨论与边角锁定

已知 △PF[[sub:1]]F[[sub:2]] 为等腰三角形，且 ∠F[[sub:1]]F[[sub:2]]P = 120°（钝角！）：
• 三角形内角和定理：一个三角形中最多只能有一个钝角，且大角对大边！
• 因为 ∠F[[sub:1]]F[[sub:2]]P = 120° > 90°，它所对的边 PF[[sub:1]] 必为最大边，所以另外两个内角只能是锐角（各为 30°），唯一可能相等的两边是 |PF[[sub:2]]| = |F[[sub:1]]F[[sub:2]]|！

4. 直线斜率与直角三角形正切定义

• 斜率定义：k = tan α（α ∈ [0°, 180°) 且 α ≠ 90°）
• 在 Rt△PAH 中（H 为 P 在 x 轴上的射影）：
  tan ∠PAH = [[frac:对边|邻边]] = [[frac:|PH|| |AH|]] = k
• 本题直线的斜率 k = [[frac:[[sqrt:3]]|4]]，已知高 |PH| = [[sqrt:3]] 时，一眼就能看出底边 |AH| = 4！
