1. 正余弦定理边角互化模板

• 正弦定理：[[frac:a| [[func:sin]] A]] = [[frac:b| [[func:sin]] B]] = [[frac:c| [[func:sin]] C]] = 2R（R 为外接圆半径）
• 边化角口诀：当条件式关于边 a, b, c 为齐次式时，直接将 a → [[func:sin]] A，b → [[func:sin]] B，c → [[func:sin]] C 代入化简；
• 三角形内角和诱导：A + B + C = π ⇒ [[func:sin]](A + C) = [[func:sin]] B，[[func:cos]] C = -[[func:cos]](A + B)，[[func:sin]] C = [[func:sin]](A + B)。

2. 诱导公式消元 & 正弦型辅助角合一变形（首选）

• 消元首选模板：利用 [[func:cos]] C = -[[func:cos]](A + B) = -[[func:cos]]([[frac:π|3]] + B)，由两角和余弦展开：
  [[func:cos]] B + [[func:cos]] C = [[func:cos]] B - ([[frac:1|2]][[func:cos]] B - [[frac:[[sqrt:3]]|2]][[func:sin]] B) = [[frac:[[sqrt:3]]|2]][[func:sin]] B + [[frac:1|2]][[func:cos]] B
• 正弦型辅助角公式：a[[func:sin]] x + b[[func:cos]] x = [[sqrt:a[[sup:2]] + b[[sup:2]]]] [[func:sin]](x + φ)（其中 [[func:tan]] φ = [[frac:b|a]]），故：
  [[frac:[[sqrt:3]]|2]][[func:sin]] B + [[frac:1|2]][[func:cos]] B = [[func:sin]](B + [[frac:π|6]])。

3. 锐角三角形隐含不等式组（重中之重）

• 定义：锐角三角形要求三个内角全部大于 0 且小于 [[frac:π|2]]！
• 已知 A = [[frac:π|3]]（已为锐角），只需保证剩下两个角 B 和 C = [[frac:2π|3]] - B 同时为锐角：
  [[cases:0 < B < [[frac:π|2]]|0 < [[frac:2π|3]] - B < [[frac:π|2]]]] ⇒ [[cases:0 < B < [[frac:π|2]]|[[frac:π|6]] < B < [[frac:2π|3]]]] ⇒ [[frac:π|6]] < B < [[frac:π|2]]（即 30° < B < 90°）。
